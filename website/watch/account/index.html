Using the API

Send your key in the X-Lyra-Key header (or as Authorization: Bearer lw_…). Every response says what it cost and what's left in X-Lyra-Credits-Remaining. With no credits left the API answers 402 Payment Required with the prices, so an agent can tell its owner what to buy.

curl -H "X-Lyra-Key: lw_your_key" https://lyraauth.com/api/watch/impact          # who moves markets (5)
curl -H "X-Lyra-Key: lw_your_key" https://lyraauth.com/api/watch/people/elon-musk # one person, full record (1)
curl -H "X-Lyra-Key: lw_your_key" https://lyraauth.com/api/watch/feed.json       # real-time stories (2)
curl -H "X-Lyra-Key: lw_your_key" https://lyraauth.com/api/watch/live/recent     # live events (10)
