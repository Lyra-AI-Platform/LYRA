How it works

Three steps. About five minutes.

If you've ever added reCAPTCHA, you already know how to add LyraAuth. Works with any framework, any language and any host.

1

Register your site

Create an account, add your domain and get a site key for the page and a secret key for your server. Your keys only work on your domain.

// Dashboard → Add site
site_key   lyra_site_…
secret_key lyra_secret_…
2

Add two lines to your form

A div where the check goes, and the script. When a visitor passes, a token goes in the form as lyraauth_token.

<!-- inside your <form> -->
<div class="lyraauth"
     data-sitekey="YOUR_SITE_KEY"></div>
<script src="https://lyraauth.com/widget.js"
        async></script>
3

Check the token on your server

Send the token and your secret to siteverify. Each token works once.

r = requests.post(
  "https://lyraauth.com/api/auth/siteverify",
  json={"secret_key": SECRET,
        "token": form["lyraauth_token"]})
ok = r.json()["success"]
const r = await fetch(
  'https://lyraauth.com/api/auth/siteverify', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ secret_key: SECRET, token })
});
const ok = (await r.json()).success;
$r = file_get_contents(
  'https://lyraauth.com/api/auth/siteverify', false,
  stream_context_create(['http' => [
    'method' => 'POST',
    'header' => 'Content-Type: application/json',
    'content' => json_encode([
      'secret_key' => $secret, 'token' => $token])]]));
$ok = json_decode($r)->success ?? false;

React, Vue, Django and WordPress examples, plus the JavaScript callbacks, are in the docs.

Switching from reCAPTCHA

Change three lines. Keep the rest.

LyraAuth uses the same pattern as reCAPTCHA v2: a site key in the page, a secret on the server and a success field in the reply. Most switches are a find-and-replace.

form.html
- <div class="g-recaptcha" data-sitekey="…">
+ <div class="lyraauth" data-sitekey="…">
- <script src="https://www.google.com/recaptcha/api.js">
+ <script src="https://lyraauth.com/widget.js">
server
- POST https://www.google.com/recaptcha/api/siteverify
+ POST https://lyraauth.com/api/auth/siteverify
{ secret, token } → { "success": true }

Callbacks carry over

data-callback, data-expired-callback and data-error-callback work the way you'd expect, so your form code doesn't change.

Your visitors' data

The whole list fits on one screen.

This is everything the widget sends when someone answers a challenge. Nothing else leaves the page.

What the widget sends

  • The answer they gave to the question
  • How long they took to answer
  • Their browser's user-agent string
  • The page it was solved on, so your key only works on your site

What it never does

  • Set cookies or use local storage
  • Use advertising IDs or fingerprint the device
  • Follow the visitor to other websites
  • Sell or share data with third parties

Answers are anonymised and used to improve Lyra's AI models, and the widget tells every visitor that in one line before they answer. Details are in the privacy policy and the DPA.

Questions

Before you switch

Is the free plan really free?

Yes. 10,000 checks a month on one site, with no card and no end date. You only pay if you need more checks or more sites.

What do my visitors see?

One short question with a few buttons or a small text box, then a tick. Try the demo at the top of this page. That's exactly what they get.

What happens to the answers?

They're used to check the visitor is human. After that they're anonymised and used to improve Lyra's AI models. The widget says this in a line under every question and links to the privacy policy, so nothing is hidden from your visitors.

Can bots get past it?

No CAPTCHA stops every bot. LyraAuth mixes more than 14 kinds of question, scores how each answer was given as well as what it was, and makes each token work once, for one site, for a few minutes. Use it with rate limits and the other checks you'd normally have on a form.

Who runs LyraAuth?

Lyra Labs, a trading name of Lyra Ventures Ltd, a company registered in the United Kingdom. Contact support@lyraauth.com or, for legal and data questions, legal@lyraauth.com.

Do I need to change my privacy policy?

Usually you add a line saying your forms use LyraAuth for spam protection and link to our privacy policy. Business customers can sign our DPA.
